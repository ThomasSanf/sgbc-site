# Cartridge collection photograph

The “Keep the cartridges” section uses a photograph of SGBC’s own collection:
Pokémon Green, Crystal, Emerald, Sapphire, and Ruby. The labels, shells,
tabletop and shadows are from the original exposure.

The source was a portrait HEIC photograph (3024 × 4032 after orientation).
The web crop uses its full width and rows 816–3407, removing the dark strip
above the table and unused space below the cartridges. It is encoded as two
sRGB WebP files at quality 88: `sgbc-cartridge-collection-840.webp` (840 × 720)
and `sgbc-cartridge-collection-1680.webp` (1680 × 1440). Neither export
contains camera or location metadata. Only the web copies are published.
